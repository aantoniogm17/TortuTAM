# Referencia visual original

`index.html` es el boceto original de la interfaz, hecho antes de definir el stack del proyecto. Se conserva aquí solo como referencia visual y de UX (paleta, tipografía, layout, flujo de pantallas) — no es código de producción y no se edita.

El frontend real se construye desde cero en [`../../src/TortuTAM.Web/`](../../src/TortuTAM.Web/) siguiendo el stack definido en [docs/planteamiento.md](../planteamiento.md), para evitar arrastrar conflictos o deuda técnica del boceto original. Mismo tratamiento que recibe el esquema heredado en [`database/schema/`](../../database/schema/).
